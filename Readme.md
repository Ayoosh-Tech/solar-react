# ⚡ Solar React Dashboard Application

## 📌 Project Overview
The Solar React Dashboard Application is a modern, responsive web application built using React. It provides a complete system for users and administrators, including authentication, dashboards, service request management, and location-based search functionality.

The application is designed to simulate a real-world platform where customers can interact with services, request quotes, and view information, while administrators and companies can manage data through dedicated dashboards.
